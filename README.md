# Autorola Sales Dashboard (Power BI)
This dashboard analyzes vehicle sales performance across Fleet & Salvage departments.

## Key Insights
- Vendor-wise top 5 performance
- YTD vs 2024/2025 comparisons
- Profitability heatmaps
- Dynamic date filters

## Skills Demonstrated
- Data modelling
- DAX (TopN, calculated tables, dynamic measures)
- Power Query transformations
- Drill-through, slicers
