# Autorola Sales Performance Dashboard (Power BI)

This Power BI dashboard analyses Autorola Australia's vehicle sales performance across Fleet and Salvage departments for 2024–2025. It is designed to help sales managers, directors, and operational teams quickly understand vendor performance, sales trends, and profitability.

---

## 🚗 Key Insights

- **Top Vendors by Sales Volume & Revenue**  
  Dynamic ranking using DAX (TOPN, RANKX).

- **Sales Trends (YTD, MTD, 2024 vs 2025)**  
  Time-intelligent calculations using a disconnected Date table.

- **Fleet vs Salvage Split**  
  Comparative analysis using dynamic measures.

- **Vendor Contribution %**  
  Pie/Donut visuals showing top contributors with “Others” grouping.

- **Department-wise KPIs**  
  Total Vehicles Sold, Total Sales Price, Avg Selling Price, Top Departments.

---

## 🧠 Skills Demonstrated

- **DAX:** TOPN, CALCULATE, SUMX, dynamic measure switching, date intelligence  
- **Data Modelling:** Relationship design, star schema, fact + dimension tables  
- **Power Query:** Cleaning, mapping vendors, merging tables  
- **Advanced Visuals:** Bookmarks, slicers, conditional formatting  
- **Reporting Design:** KPI cards, trend lines, department filters, drill-through  
- **Business Analysis:** Vehicle sale insights, vendor performance tracking
